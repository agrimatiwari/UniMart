# UniMart

UniMart is a frontend-only student marketplace prototype for the Thapar campus. It is built with HTML, CSS, and vanilla JavaScript; no backend, payment processing, or delivery service is included.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` with the Live Server extension (or serve the folder with any static web server).
3. Browse the sample listings, or use **My profile** to register/verify a demo student profile.

## Local demo data

Listings, profile details, enquiries, wishlist items, recently viewed items, and theme preference are stored in the current browser's LocalStorage. Uploaded listing photos are resized in the browser and stored locally as well. This data is not uploaded or shared with other people, browsers, or devices. Reset demo data from **Settings**.

Student verification and sign-in are simulated for this prototype and do not contact Thapar systems. Do not enter sensitive personal information. Public profiles mask email/student identifiers, and personal contact details are not shown on listings.

UniMart only connects buyers and sellers. Arrange exchanges directly in a safe, public campus location; UniMart does not process payments, provide delivery, or guarantee transactions.
